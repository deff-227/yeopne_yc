신예찬 휴대폰 · 중콘 에디션

index.html: 신예찬 폰 (첫 화면)
sangyeop.html: 기존 최상엽 폰
각 폰의 이동 버튼으로 오갈 수 있다.

GitHub Pages에 올리기
압축을 풀고 index.html, sangyeop.html, yechan.js, yechan.css 및 나머지 모든 파일과 assets 폴더를 같은 위치에 올린다.
새 index.html은 예찬 폰을 먼저 연다. 기존 주소를 덮어쓰면 첫 화면도 예찬 폰으로 변경된다.
상엽 폰을 먼저 열고 싶다면 sangyeop.html로 접속한다.
로컬에서도 index.html을 열 수 있으나, 사진 저장은 GitHub Pages 등 HTTPS 환경에서 사용하는 것을 권장한다.

데이터 범위
메모, 좋아요, 카톡 및 사진은 각 브라우저에만 저장된다.
두 폰의 새 메시지가 실시간으로 연동되거나 다른 기기에 동기화되지는 않는다.
기존 상엽 폰은 예찬 폰으로 이동하는 링크 외에는 보존했다.
최신 버블과 설이 사진은 추후 제공받아 반영할 예정이다.
